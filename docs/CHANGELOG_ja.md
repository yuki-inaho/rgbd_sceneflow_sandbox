# 第0.3版の変更と、採用しなかった主張

## 定式化

観測由来の固定剛体変位補助項と、ベクトル幾何Huberを追加しました。
対応・支持・境界・剛体補助場を前処理後に固定し、有限対応選択と凸部分問題を交互に扱います。
剛体推定自体は外れ値を弱めた当てはめであり、大域最適性を保証しません。
基礎情報を二度使用するため、補助項を独立な観測に基づく確率的な事前分布とは呼びません。

グラフ二階正則化は全勾配型です。対称勾配TGVとは同一ではありません。
同じ奥行きの独立運動に対して剛体補助項が誤差を増やす負の対照も記録しました。
欠測深度の完全補完、カメラ運動の推定、照明に対する完全不変性は実装していません。

## 速度

階層的な有限探索、スタック上のパッチ配列、重複灰度成分の省略、計算融合を追加しました。
双対初期値の再利用と内側反復数の変更は切替可能です。
探索縮小は問題の候補集合を変え、反復打切りは到達点を変えるため、全部を同値変形の高速化とは扱いません。
同値な計算核変更のみの経路と、融合なしの参照経路で配列の数値差を記録しています。

対角前処理は前版に既に存在しました。今回はその条件を証明して明示しました。
GPUや並列実行を使用して性能を上げたものではありません。

## 評価

基準は球・立方体等を描画した第0.2版であり、平面中心の第0.1版ではありません。
6入力の再試験、新規の形状・姿勢・模様・運動を持つ6入力、19構成、8つのストレス条件を評価しました。
推定器に正解ラベル・可視性・変位を渡していません。
「初期フローが正解＋雑音」という実験ではなく、全主比較でDISを画像から実行しています。
追加の他エージェント資料は確認できず、独立した外部実験として計上していません。

旧フィールド max_estimated_motion_mm がメートル値だった不備を修正しました。
保存された変位からmmへ再計算し、修正履歴を残しました。既存の端点誤差と時間には影響しません。
新方式の深度RMSEと幾何残差の増加も、変位誤差とは別の表で示します。

## 理論書の構成

入力・座標・未知量、有限候補、剛体補助項、離散作用素、全目的関数、近接写像、証明、
実験設計、数値結果、反例、再現方法の順に整理しました。
実測値を数式の保証として扱わず、固定対応での凸性と全体の非凸性を区別します。
前処理ノルムの値は測定した最大特異値ではなく証明済み上界です。
固定点残差は最適解との距離でも主双対ギャップでもありません。
同じ入力の各方法について、目的値を自動で比較可能とはしていません。

## 再現性

環境依存の共有ライブラリと仮想環境は配布しません。
比較用の第0.2版ソースと必要な7つの保存入力をコード版へ含めます。
コードを新規展開して再ビルドし、自動試験と代表入力の再計算を実施しました。
uvを利用しましたが、外部取得を伴う新規依存解決の成功までは主張しません。

配布点検で、旧v0.1比較器が新しい統計フィールド一覧を参照する互換性不備を修正しました。旧ABIの10項目を独立定義し、回帰試験を追加しています。v0.2／v0.3の70件の保存推定・計測値には影響しません。
